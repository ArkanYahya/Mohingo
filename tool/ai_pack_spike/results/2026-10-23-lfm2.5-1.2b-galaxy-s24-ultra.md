# 2026-10-23 — LFM2.5 1.2B Instruct (Q4_K_M) on a Galaxy S24 Ultra

Spike build `a815cdd` (prompt v2: `is_english` and `missing` before the verdict, "strict", one worked example; Fast mode, default threads; the native runtime still on the `compact` CPU profile, see below).

## Reading

- **Memory:** 241 MB → 1225 MB after load, 1355 MB peak. 160 MB less than Gemma 3 1B; the smallest footprint so far.
- **Speed:** median 18.3 s. The new timing line is the finding: **prompt evaluation 14.0 s of it**, generation 2.9 s, grammar sampling 0.9 s. Every answer re-evaluated the whole ~470-token prompt (the `prompt tokens` column), where Gemma reused the cached prefix after the first answer (293 then 6-66 tokens): LFM2's hybrid convolution/attention architecture has no reusable KV prefix in llama.cpp. And the prompt rate itself was ~34 tokens/s on a 2024 flagship, a tenth of what a 1.2B model should do — the spike's pubspec had chosen `cpu_profile: compact`, which ships the ARMv8.0 baseline kernel alone, without the dotprod/i8mm kernels every phone since 2020 has. Build v3 restores the full profile; the speed numbers of runs 1 and 2 are both to be redone.
- **Judgement:** none, in a new way. All 22 verdicts true again, grammar 0 everywhere again. The `missing` field read "one thing you don't like" on 18 of 22 answers, whatever the task — the prompt's worked example (a likes task), copied. Where it did not copy (the email cases, the shop case) it said "nothing" for answers missing a part. And the rule "answers_task is true only if missing is nothing" was ignored every time: missing non-empty, verdict true. The English explanations were sometimes on topic ("The answer needs to include name, country, and job") but did not match the verdict.
- **Arabic:** not asked in Fast mode.

What this decides: a model of this size cannot be asked for a verdict, a count or a rule. Prompt v3 asks it only for what it can do — true/false per named requirement, with the names fixed by the JSON schema, and a list of mistakes — and computes the verdict and the count in code; whether the answer is English is decided from its script, not asked. No worked example.
